## (후속 #1) 첫 살인(S1E3) 직후, 월터가 스스로를 정당화한 “논리”는?

1. **S1E2** / 크레이지-8을 RV 밖에서 붙잡아 **지하실에 감금** / “살려두면 위험”이 현실화됨
    
2. **S1E2~E3** / 월터가 크레이지-8과 대화하며 **인간적으로 동요** / “내가 괴물이냐?” 자문 시작
    
3. **S1E3** / 월터가 **장단점 리스트**(살려둘지 말지) 작성 / 자기합리화의 ‘논리형’ 템플릿 생성
    
4. **S1E3** / 접시 조각(무기)이 사라진 걸 알아차림 / “이건 선택이 아니라 생존”으로 프레이밍 전환
    
5. **S1E3** / 월터가 크레이지-8을 **목 졸라 살해** / 결론: “나 아니면 내 가족이 죽는다”
    
6. **S1E3** / 시신 처리(해체/폐기) 수행 / “되돌릴 수 없음”이 확정되며, 정당화가 더 굳어짐
    
7. **S1E3** / 이후 가족에게 **거짓말로 시간/행적 메움** / “가족 보호” 명분이 실무로 들어감

## (후속 #2) 첫 살인 이후, 월터가 폭력에 ‘익숙해진 징후’가 처음 보이는 사건은?

1. **S1E3** / 살인 직후에도 **시신 처리까지 완수** / 공포 속에서도 ‘업무 수행’ 가능해짐
    
2. **S1E4** / 월터가 일상 복귀를 시도하면서도 **거짓말을 유지** / 죄책감보다 “관리”가 앞서는 패턴
    
3. **S1E6** / 투코를 상대로 **폭발(수은 풀미네이트) 시연**으로 협상 주도 / 폭력(위협)을 “도구”로 사용
    
4. **S1E6** / “상대가 무서워하도록” 연출을 계산 / 폭력의 심리 효과를 학습
    
5. **S1E7** / 투코 거래 구조에 들어가며 **리스크를 감내** / “위험한 판”을 피하지 않음이 확정
    
6. **S1E7** / 위협이 커져도 도망 대신 **다음 수를 고민** / 공포보다 통제가 우선하는 방향성

## (후속 #3) “전략적 살인” 단계로 넘어가게 만든 외부 압력(위협/수사/조직)은?

1. **S1E6~E7** / 투코라는 폭력적 바이어 등장, 거래가 **생존게임**이 됨 / “상대가 규칙”인 세계 진입
    
2. **S2 전반** / 수사(DEA)와 주변 의심이 쌓이며 **은폐 비용 폭증** / 실수=체포/가족 붕괴 리스크
    
3. **S2 후반** / 더 큰 유통 구조(조직형 파트너)로 들어가며 **대체 가능성**이 생김 / “버려질 수 있음” 압력
    
4. **(이후 시즌)** / 조직이 “협력”에서 “통제”로 바뀌는 순간들 / 제거(살인)를 ‘옵션’으로 계산하게 됨
    
5. **(이후 시즌)** / 가족이 직접 위험권에 들어오는 압력 / “협상으로 못 풀면 제거”로 사고가 이동
    
6. **(이후 시즌)** / 수사망·조직 규칙·배신 가능성이 겹치며 **선제 행동**이 유리해짐 / 전략적 살인의 완성 조건

## (후속 #4) 월터가 살인을 “선택지로 계산”하기 시작한 첫 순간은?

1. **S1E2** / RV에서 독성가스로 에밀리오·크레이지-8 무력화 후, 크레이지-8을 **살려둘지** 문제 발생
    
2. **S1E2** / 월터가 크레이지-8을 **지하실에 결박·감금** / “즉흥 폭력”에서 “관리 단계”로 이동
    
3. **S1E3** / 월터가 ‘살릴지 죽일지’ **장단점 리스트** 작성 / 살인을 감정이 아니라 “의사결정”으로 구조화
    
4. **S1E3** / 접시 조각(무기)이 사라진 걸 보고 **위협 재평가** / ‘살려주면 내 가족이 위험’으로 계산 업데이트
    
5. **S1E3** / 월터가 **살해 실행** / “계산→결정→실행” 루프가 첫 완성

## (후속 #5) 살인이 주변 인물(제시/스카일러/행크)에 만든 2차 파장은?

1. **S1E3** / 월터·제시가 시신 처리/증거 정리를 하며 **관계가 ‘공범 구조’로 고정** / 제시의 죄책감·불안 가속
    
2. **S1E2~E4** / 월터의 실종/이상행동 누적 → 스카일러가 **의심을 ‘패턴’으로 인식** / 감정적 의심이 구조적 의심으로
    
3. **S1E4** / DEA가 하이젠베르크/메스 사건을 더 크게 보기 시작 → 행크의 수사가 **“우연한 마약범”에서 ‘제조자’ 추적**으로 확장
    
4. **S1E5~E7** / 월터의 거짓말 유지 비용 증가 → 가족 갈등이 커지고 **은폐 행동이 더 공격적으로 변함**
    
5. **S1E6~E7** / 투코 라인 진입 → 폭력/위협이 현실화되어 주변 인물들이 체감하는 “위험 반경” 확대
