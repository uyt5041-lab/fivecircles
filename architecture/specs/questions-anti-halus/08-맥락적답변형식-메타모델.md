우리디비에 맞춰 코드명, 컬럼명 등을 리팩토링 반드시 필요.
Q1–Q15를 관통하는 Level 1–3을 공통 추상 구조로 정의하고,그걸 predicate 코드셋에 매핑한다.
드라마 기준 예시: Breaking Bad

🧠 1️⃣ Level 공통 메타 모델 정의
Level을 단순 “초기/중간/후반”이 아니라**구조 변화 강도(Intensity of Structural Change)**로 정의한다.

🔹 LEVEL 1 — Anchor Event (점 발생)
개인 단위의 최초 사건구조는 아직 바뀌지 않음
특징:
* 단발성
* 개인 선택/행동
* 시스템 변화 없음
예:
* 첫 살인
* 첫 제조
* 첫 의심

🔹 LEVEL 2 — Structural Shift (선 형성)
반복 구조 또는 관계 구조가 형성됨
특징:
* 계약·파트너십·반복 수익
* 신뢰 붕괴
* 지속 위협 구조
예:
* 투코와 대량 계약
* 반복 거짓말 체계
* 수사 방향 전환

🔹 LEVEL 3 — Systemic State (면 형성)
시스템화·산업화·권력 고정 상태
특징:
* 조직 구조 확립
* 산업적 규모
* 제도화된 은폐
예:
* 거스 제거 후 장악
* 세탁 시스템
* 범죄 제국 완성

📐 2️⃣ 메타 모델 스키마 제안
event
 ├─ predicate_code
 ├─ structural_weight (1|2|3)
 ├─ domain_type (THREAT | POWER | MONEY | RELATION | IDENTITY | INVESTIGATION)

아래는 Q1–Q15를 기준으로 공통 분류한 매핑표.

🧩 4️⃣ Q1–Q15 자동 분류 원리
예시:
Q10 (위협)→ domain = THREAT→ predicate_code 매칭→ structural_weight 자동 계산
UI는:
Level 1: 개인 생존 위협
Level 2: 조직적 통제 위협
Level 3: 시스템 지배 위협

🏗 5️⃣ 시스템 적용 방식 (MVP 기준)
✅ MVP에서 가능한 것
* predicate_code → level 매핑 테이블 추가
* 조회 시 group by structural_weight
* 3단계 응답 자동 생성
⛔ 추후 패치 후보
* 도메인 자동 추론 NLP
* structural_weight 자동 계산
* 다중 domain 교차 레벨링

📊 최종 구조 요약
Level 정의는 더 이상 드라마 종속 개념이 아니다.
Level	구조 의미	시스템 상태
1	점	최초 발생
2	선	반복·관계 형성
3	면	시스템화
이제 질문 하나가 들어오면:
1. domain 판별
2. predicate 그룹 매칭
3. structural_weight 1→3 출력
으로 자동 생성 가능하다.
