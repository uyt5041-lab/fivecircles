🔥 Q5
“월터가 ‘범죄를 해야겠다’고 결심한 순간은 언제이며, 그 결심은 어떻게 성격이 바뀌는가?”

🔹 Level 1 — 생존 목적 결심
🎯 S1E1 (Pilot)
* 폐암 진단을 받음.
* 세차장에서 굴욕을 겪음.
* DEA 단속 현장에서 마약이 큰 돈이 된다는 사실을 확인.
* 제시를 찾아가 “같이 만들자”고 제안.
이 시점의 동기:
“내가 죽은 뒤 가족이 가난에 빠지지 않게 하기 위해.”
👉 범죄는 수단이고, 가족은 목적.👉 Survival-driven crime entry

🔹 Level 2 — 자존심 기반 지속
🎯 S1E5 (Gray Matter)
* 엘리엇이 치료비 전액 지원 제안.
* 합법적으로 문제 해결 가능해짐.
* 월터는 도움을 거절.
이 장면이 중요한 이유:
* 이제 범죄는 “불가피한 선택”이 아님.
* 자존심과 열등감이 의사결정을 지배.
👉 동기 이동:
가족 생존 → 개인 자존심
👉 Pride-dominant continuation

🔹 Level 3 — 권력 욕망으로 전환
🎯 S4~S5
* 거스를 제거하고 조직 장악.
* “I did it for me.” 고백.
이 시점에서:
* 가족은 명분일 뿐.
* 범죄는 정체성.
👉 Identity-based domination

🕵️ Q7
“월터의 거짓말은 언제 처음 균열이 생기고, 어떻게 붕괴되는가?”

시간순 도미노(레벨 통합)

🔹 Level 1 — 이상 행동 노출 (S1E2)
1) `#3012` (EP2, `OTHER`)
- 병원 실종/행적 공백 등 이상 신호가 관측되며 의심이 착화된다.

2) `#3016` (EP2, `OTHER`)
- 스카일러가 월터의 공백 행적을 근거로 직접 추궁한다.

3) `#3013` (EP2, `OTHER`)
- 월터가 제시 관련 커버스토리로 거짓말을 시작한다.

4) `#3017 -> #3014 -> #3018 -> #3015` (EP2)
- 검증 결정 -> 제시 대면 검증 -> 신뢰 하락 -> 거짓말 패턴 고착.

PRECEDES(운영 반영)
- `3012 -> 3016 -> 3013 -> 3017 -> 3014 -> 3018 -> 3015`

👉 Behavioral suspicion stage

🔹 Level 2 — 구조적 불신 (S2)
1) `#3001` (S2E2, abs EP9, `OTHER`)
- "Which one?" 실수로 두 번째 폰 존재가 노출된다.

2) `#3002` (S2E2, `DISCOVERS`)
- 스카일러가 이중생활 의혹을 사실상 확신한다.

3) `#3003` (S2E2, `OTHER`)
- 월터의 부정/변명이 반복되며 신뢰가 추가로 소모된다.

4) `#3004` (S2E4, abs EP11, `OTHER`)
- 스카일러가 변명을 거짓말로 판정한다.

5) `#2923` (S2E13, abs EP20, `BETRAYS`)
- 불신이 관계 구조 붕괴(별거/퇴거 국면)로 고착된다.

PRECEDES(운영 반영)
- `3001 -> 3002 -> 3003 -> 3004 -> 2923`

👉 Trust collapse phase

🔹 Level 3 — 명시적 폭로 (S3E2)
1) `#2922` (S3E2, abs EP22, `DISCOVERS`)
- “I cook meth.” 수준의 명시적 인지 구간(범죄 사실 확정 인지).

연결 메모
- 현재 DB PRECEDES에는 `2923 -> 2922`가 반영되어 있다.
- 레벨1~레벨2 연결을 위해 `3015 -> 3001`을 반영했고, 이로써 Q7이 단일 도미노 체인으로 조회된다.

👉 Explicit confession

🔎 Q7 웹 검증 도미노(운영 반영용 보강안)

아래 체인은 에피소드 플롯 근거로 재정리한 Q7 권장 도미노다.

1) S2E2 `Grilled`  
- 마리/행크 대화로 "월터의 두 번째 폰" 의심이 스카일러에게 노출됨.

2) S2E3 `Bit by a Dead Bee`  
- 스카일러가 월터에게 "두 번째 폰이 있냐"고 직접 확인.  
- 월터는 부인하고, 신뢰 균열이 명시적 질문 단계로 진입.

3) S2E4 `Down`  
- 월터가 "벨소리가 아니라 약 복용 알람"이라고 추가 변명.  
- 스카일러가 대화에서 이탈(관계 신뢰 하락 가속).

4) S2E13 `ABQ`  
- 수술 직전 월터의 "Which one?" 발화로 두 번째 폰 의혹이 사실상 확정.  
- 스카일러가 다른 거짓말(엄마 방문, 치료비 출처, 실종 서사)을 연쇄 검증하고 퇴거 요구.

5) S3E1 `No Más`  
- 이혼 압박 국면에서 월터가 메스 제조 사실을 시인(명시적 폭로 단계).

현재 운영 데이터와 PRECEDES 연결(제안/반영)
- 기존 체인: `3001 -> 3002 -> 3003 -> 3004 -> 2923 -> 2922`
- 레벨1 연결 보강: `3015 -> 3001` (반영)
- 통합 도미노: `3012 -> 3016 -> 3013 -> 3017 -> 3014 -> 3018 -> 3015 -> 3001 -> 3002 -> 3003 -> 3004 -> 2923 -> 2922`
