# Event V2.5 Definition + Plan

Purpose
- V2에서 V3로 가기 전, predicate_code 기반 분석(Q20) 및 **문맥 인식형 QA 컴포넌트**를 오픈한다.
- Level 4 질문 중 **Q20(서사 분포)**을 우선 지원하며, 이를 모든 페이지에서 호출 가능하게 한다.

Definition (V2.5)
- **데이터 모델**: V2 유지 + **V3 대비 `role` 컬럼 선반영**.
- **Schema**: `event_character` 테이블에 `role` 컬럼 추가 (Default: `'INVOLVED'`) + 역할 인덱스 2종(`event_id, role, character_id` / `character_id, role, event_id`).
- **QA Strategy**: 페이지마다 개별 UI를 만드는 대신, 문맥(Context)을 주입받아 동적으로 질문을 제안하는 **`ContextQAButton`** 공통 컴포넌트 기반으로 구현.
- **범위**: Q20(서사 분포) 지원 + Q1~Q15 연동.

## 1. Backend Alignment

### 1.1 DB Schema Update (V6)
- `services/event-service`에 `V6__event_v3_triple_roles.sql` 적용.
- `ALTER TABLE event_character ADD COLUMN role VARCHAR(20) DEFAULT 'INVOLVED'`.
  - Index: `idx_ec_event_role_character` on `(event_id, role, character_id)`
  - Index: `idx_ec_character_role_event` on `(character_id, role, event_id)`
   - `EventServiceImpl`의 하드코딩된 `PARTICIPANT`를 `INVOLVED`로 수정 완료.

### 1.2 Predicate 표준 확정
- 표준 코드 목록은 `ex13-standard-predicates.md` 기준 사용.
- FE/QA에서 집계 및 필터링 시 해당 코드를 Key로 사용.

## 2. Frontend Implementation: Question Button + Drawer

### 2.1 Component: `QuestionButton`
- **Location**: `front/features/qa/components/QuestionButton.tsx`
- **Goal**: 질문 1개 = 버튼 1개. 각 버튼은 고정된 질문을 호출하며, 결과는 Drawer(또는 Modal)에서 표시한다.
- **Testing**: `/qa` 페이지에 Q1~Q15 버튼을 전부 배치해 테스트(최초 구현).

### 2.2 Question Logic & Mapping
Event Service의 API를 활용하여 Q1~Q15를 각각 매핑하고, Q20은 추가 분석으로 처리.
질문별 API 매핑은 `event-v2-plan-map.md`를 기준으로 참조한다.

| Level | 질문 예시 | 처리 방식 (API) |
|---|---|---|
| **L1 (Fact)** | "이 인물은 언제 나오나?" (Q1) | `getCharacterEvents` |
| **L2 (Search)** | "키워드 사건 검색" (Q2) | `searchEvents` |
| **L3 (Logic)** | "스포일러인가?" (Q13) | `policy/check` |
| **L4 (Anal)** | "서사 분포 분석" (Q20) | `getCharacterEvents` + Client Aggregation |

### 2.3 Implementation Structure
- `front/features/event/components/`
    - `EventQAButton.tsx`: 진입점 (Trigger).
    - `EventQADrawer.tsx`: 질문 목록 및 결과 컨테이너.
    - `widgets/`: 질문별 개별 컴포넌트 (Factory Pattern).
        - `Q1_Appearance.tsx`
        - `Q20_Distribution.tsx`
        - ...

## 3. Q20: 인물 서사 분포 분석 (V2.5 핵심 기능)

- **질문**: "인물 A의 서사가 어떤 사건 카테고리에 가장 많이 걸쳐 있나?"
- **로직**: `ContextQAButton`에서 캐릭터 컨텍스트일 때 '분석하기' 옵션 제공.
- **처리**: `eventV2Api.getCharacterEvents` 호출 -> `predicateCode`별 카운트 -> 상위 N개 차트화.
- **출력**: `PredicateCode` 설명(사망, 배신 등)과 함께 분포 리스트 출력.
