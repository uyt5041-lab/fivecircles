# Requirements Space

이 폴더는 “요구사항을 쓰고, 논쟁하고, 확정하는” 공간입니다.

## 파일 역할
- current.md: 분석 전 요구사항(작업용)
- REQUIREMENTS.md: 분석 후 결정된 사항(권위 높음)
- debates/: 불명확/충돌 사항에 대한 논쟁 기록(질문/가설/결론)

## Debate 규칙(추천)
1) 모순/불명확을 발견하면 debates/에 파일을 만든다.
2) 각 주장에는 근거와 영향 범위를 적는다.
3) 결론이 나면 REQUIREMENTS.md에 “확정”으로 옮기고 current.md를 갱신한다.
